# C++ Constructor and Destructor

## Description
This program demonstrates how constructors and destructors work in C++ using a simple `Demo` class.

## Concepts Used
- C++ Classes and Objects
- Constructor
- Destructor
- Object Creation and Destruction

## Output
```text
Creating Object...
Constructor is executed.
Object is being used.
End of main().
Destructor is executed.
```

## How to Run
1. Compile the program:
   `g++ constructor_destructor.cpp -o program`
2. Run the program:
   `./program`
